# 変更履歴

[English](../en/changelog.md) · [README](../../README.ja.md)

| バージョン | 主な変更 |
|---|---|
| 未リリース | 通常FST、暗号化FST、ZIPに既定の展開容量上限を適用し、修復時も検査。エントリー数、チャンクサイズ、展開パスを検査。フォルダー書庫を一時ファイルから確定し、フォルダーFSTとZIPは全エントリーの検証後に展開先を確定。Windows・LinuxのCIを追加。 |
| 1.2.3 | 単一ファイルFSTを一時ファイルのメモリマップに直接展開し、バッチごとに全体ハッシュを更新。 |
| 1.2.2 | 大容量FST圧縮でZstandardの作業領域を再利用し、rawチャンクのコピーを削減。分析と全体ハッシュ計算も一部並行化。 |
| 1.2.1 | 大容量の復旧データ作成・修復を並列化し、バッファを再利用。 |
| 1.2.0 | FST・ZIP用の任意のReed–Solomon復旧データと修復を追加。 |
| 1.1.1 | GPU転送量を削減し、CPUでの境界採点を並列化。 |
| 1.1.0 | ファイル・フォルダーの暗号化を追加。16 MiB未満の入力の境界採点をCPUに限定。 |
| 1.0.2 | FST・ZIPの展開と検証を修正し、処理速度を改善。 |
