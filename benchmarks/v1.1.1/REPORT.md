# Fastener 1.1.1：追加高速化

2026-09-25。1.1.0と1.1.1の独立したリリースEXEを同じディレクトリに配置して比較しました。Windows x86_64、NVIDIA GeForce RTX 5070 Ti、15ワーカーです。

## 変更内容

- GPUには全入力ではなく、採点対象の16バイトおきの値だけを転送。64 MiB区間では64 MiB → 4 MiB＋4バイトになります。
- サンプルの実数をシェーダーに渡し、末尾のパディングを採点から除外。
- 256ブロック以上のCPU採点はRayonで並列化。それ未満は逐次処理を維持。
- 境界の選び方、圧縮形式、暗号化の鍵導出条件、認証・チェックサム検証は変更していません。

## 測定方法

`run.ps1`が固定シードの入力を生成し、各ケースでウォームアップ1回＋本測定5回、旧版と新版の実行順を交互にします。プロセス起動・入出力を含み、OSキャッシュは消去しません。復元SHA-256計算は計測時間から除きます。バイナリのSHA-256は`manifest.json`、全測定は`measurements.json`、中央値は`summary.json`にあります。

初回は配置ディレクトリが異なり、変更していない解凍処理にも大きな差が出ました。その記録は`exploratory-*.json`に残し、下表には配置を揃えた再測定のみを使います。初回との差の原因は断定していません。

## 検証と限界

全ケースで圧縮後に検証・展開し、復元SHA-256を元データと比較しています。暗号化の速度は今回測定していません。暗号化でも共通の解析処理を使いますが、Argon2idの処理時間は変わりません。GPU初期化自体のコストも残ります。転送量が16分の1になることと、処理時間が16分の1になることは異なります。

## 再現

旧版・新版EXEを同じディレクトリに用意し、次を実行します。測定用EXEと入力データは配布ZIPに含めません。

```powershell
./run.ps1 -BeforeBinary ./bin/before.exe -AfterBinary ./bin/after.exe
./summarize.ps1
```

## 実測結果（中央値）

| ケース | 圧縮 旧→新 ms | 短縮率 | 展開 旧→新 ms | 検証 旧→新 ms |
|---|---:|---:|---:|---:|
| mixed-balanced (256 MiB) | 792.46 → 748.62 | 5.53% | 260.31 → 266.74 | 154.96 → 160.28 |
| mixed-fast (256 MiB) | 786.35 → 760.50 | 3.29% | 270.05 → 265.51 | 152.96 → 154.97 |
| random-balanced (128 MiB) | 782.03 → 765.20 | 2.15% | 189.97 → 194.83 | 132.21 → 127.76 |
| small-balanced (1 MiB) | 107.19 → 107.21 | -0.03% | 105.44 → 105.65 | 99.73 → 106.35 |

全48回（ウォームアップを含む）で復元SHA-256が一致し、各ケースのアーカイブSHA-256も旧版・新版で一致しました。大容量の圧縮時間は今回の環境で約2〜5.5%短縮しました。1 MiBの既定設定では解析自体が省略されるため、今回の変更による高速化は確認できません。解凍・検証は変更しておらず、表の差を今回の最適化の効果とは扱いません。

## 正確性の検査

- GPU機能を含むテスト44件、CPUのみのテスト42件が成功。
- RTX 5070 Ti上で、GPU＋CPUの採点が逐次参照実装と同じ採点に一致することを確認。
- GPUの部分ブロック・末尾長と、CPU並列採点を追加検証。
- 暗号化の改ざん拒否、既存出力保護、GUI操作経路の回帰テストも成功。
- Clippy（全ターゲット・全機能、警告をエラーとして扱う）とフォーマット検査も成功。
